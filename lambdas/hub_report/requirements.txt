# runtime deps. RD-045 CONTRACT-FIRST decision (mirrors RD-041 / RD-042): this step is an

# side (dynamodb:GetItem; no query/scan — the report is per-intake). boto3 is provided by
# the Lambda runtime; pinned here for local/dev parity. This Lambda does NOT validate its
# own output at runtime (it BUILDS a bounded payload whose bounds are enforced in code), so
# it needs no jsonschema at runtime — the plain asset suffices (no Docker bundling, exactly
